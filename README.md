# 拾贝小镇 · Shell Town

> 一个面向家庭的自托管「积分 + 任务 + 宠物养成」系统。
> 孩子通过完成日常任务、临时任务赚取积分，用积分兑换奖励、现金，或购买道具喂养自己的宠物；
> 家长负责审核、规则设置与宠物物种管理。
> 数据全部保存在本地（SQLite + 本地图片目录），不上传任何云端。

---

## 功能特性

### 👨‍👩‍👧 家长端
| 模块 | 说明 |
|---|---|
| **总览** | 查看所有孩子的积分、今日积分变化、待审核数量 |
| **积分** | 设置日常加分/扣分项目（可限制每日次数），一键为孩子加减分 |
| **任务** | 发布临时任务（含分类、积分奖励、截止时间） |
| **审核** | 审批孩子提交的任务完成申请、商品/现金兑换申请 |
| **商店** | 管理可兑换的商品（名称、所需积分、库存）；可上架**宠物道具**（喂食、玩耍，即时生效） |
| **宠物** | 管理宠物物种：新建宠物、改中文名、设各阶段成长阈值、上传各阶段形象图 |
| **记录** | 查看全部积分流水明细与操作人 |

### 🧒 孩子端
| 模块 | 说明 |
|---|---|
| **主页** | 查看自己的积分余额、男生/女生预置或自定义形象头像、等级进度 |
| **宠物** | 领养宠物、给它起名、看进化图鉴、用积分道具喂养进化 |
| **任务** | 领取任务、提交完成，等待家长审核 |
| **商店** | 用积分兑换商品、宠物道具，或申请兑换现金 |

### 🐾 宠物养成
- **12 只原创虚构生物**：男生款 6（焰灵/雷角/岩铁/疾风/幼龙/暗影）+ 女生款 6（泡灵/芽芽/霜晶/月蛾/菌菇/星辉）
- **5 段进化**：神奇蛋 → 幼生体 → 成长期 → 完全体 → 究极体，每阶段独立立绘
- 孩子领养时自选物种并可起昵称；**换物种会重置等级与状态值**
- 用积分买**宠物道具**喂养，即时生效（不走家长审核），经验按宠物当前心情加成/打折
- 三项状态值：饱食度 / 快乐值 / 健康值，随时间缓慢衰减（**每 12 小时结算一次，一次 -4/-3/-2**，合计每日 8/6/4；最多累计 5 天，出远门回来宠物不会"饿死"）
- 心情由状态值推导（超级开心 / 还不错 / 有点委屈 / 肚子好饿），只影响表情与经验倍率（1.5× / 1.0× / 0.6× / 0.5×）
- 每只物种的**成长阈值可单独配置**（默认 0 / 20 / 70 / 150 / 280 经验）

### ✨ 其他
- 家长用 **账号 + 密码** 登录；孩子用 **账号 + PIN 码** 登录（无需记密码）
- **登录安全**：PIN 码 bcrypt 哈希存储（老库启动时自动迁移）；家长/孩子登录连续失败 5 次锁定 15 分钟防爆破
- 内置 **男生 / 女生两组预置形象**，并支持**自定义捏脸编辑器**（自由搭配部件与配色）
- 响应式设计，手机 / 平板 / 电脑均可使用
- 支持积分兑换比例自定义（如 10 积分 = 1 元）
- 支持 WebSocket 实时更新（家长端审核数、宠物领养/进化即时刷新）

## 宠物养成系统

### 成长阶段

| 阶段 | 名称 | 累计经验（默认） | 形象来源 |
|---|---|---|---|
| 0 | 神奇蛋 | 0 | `_egg.webp`（通用蛋图） |
| 1 | 幼生体 | 20 | `<key>/1.webp` |
| 2 | 成长期 | 70 | `<key>/2.webp` |
| 3 | 完全体 | 150 | `<key>/3.webp` |
| 4 | 究极体 | 280 | `<key>/4.webp` |

> 阈值可按物种在家长端「宠物」页单独调整；经验来自商城里的**宠物道具**（`pet_effect`，如 `{"exp":40}` 或 `{"satiety":25,"happiness":10}`）。

### 数值机制

- **状态值**：饱食度 / 快乐值 / 健康值（0~100），初始 70 / 70 / 85
- **自然衰减**：每天 -8 / -6 / -4，**按 12 小时一个整刻度结算**（一次 -4/-3/-2），惰性结算（无后台任务）；
  只推进真正扣掉的整刻度、零头留给下次，所以**衰减量与孩子查看宠物的频率无关**；
  最多累计 **5 天**，长期不登录也不会把宠物饿没
- **心情**：由最低的状态值推导，只影响表情与经验倍率
- **经验倍率**：超级开心 1.5× · 还不错 1.0× · 有点委屈 0.6× · 肚子好饿 0.5×

### 宠物素材目录

```
pets/
├── _egg.webp                 # 通用蛋图（阶段 0）
├── pyro/                     # 物种 key = 目录名
│   ├── 1.webp                # 阶段 1
│   ├── 2.webp
│   ├── 3.webp
│   └── 4.webp
├── volt/
└── ...
```

素材可以**两种方式**管理，都无需改代码、无需重建镜像：

1. **家长端「宠物」页**：新建物种 → 直接在卡片上点对应阶段上传图片（PNG / WebP / JPG，单个上限 10MB，服务端按文件魔数验型）。改动会实时推送到所有在线端
2. **直接放文件**：往宿主机 `./pets/<key>/` 放图，刷新页面即生效（服务端静态文件每次请求实时读盘；手动放文件服务端不知情，不会主动推送）

> **Docker 部署时**：镜像内置一份出厂素材（`/app/pets-default`），容器启动时自动把挂载目录里**缺失**的文件补齐到 `./pets`，
> 只补缺失、**绝不覆盖**你改过或上传的图。所以首次挂载无需手动拷贝素材。

### 新增一只宠物

- **换图 / 加阶段图 / 换蛋图**：往 `./pets/<key>/` 放文件即可（见上）
- **加新物种**：家长端「宠物」页 → 新建（填中文名 + 目录 key + 系列 + 阈值），再上传图片，全程零代码
- 内置 12 只允许改名、换图、调阈值，但**不允许删除**（避免历史养成数据变成孤儿）

> **改动何时生效？** 家长端的新建 / 改名 / 换图 / 删除会通过 WebSocket 广播给所有在线端，
> 孩子端**无需刷新页面、更不需要重启容器**：已打开的孩子端会自动重拉物种目录并重新加载立绘。
> （即使 WS 暂时断开，孩子端每次进入宠物页或打开「选择宠物」弹窗时也会重新拉一次目录作为兜底。）

## 快速开始（Docker 部署）

### 方式一：Docker Compose（推荐）

```bash
# 1. 进入项目目录（含 docker-compose.yml 的那一层）
cd shell-town-server

# 2. 构建并启动
docker compose up -d --build

# 3. 查看状态
docker ps
```

启动后浏览器访问：

```
http://<你的NAS或服务器IP>:3000
```

### 方式二：Docker 命令

```bash
# 构建镜像
docker build -t shell-town:latest .

# 运行容器
docker run -d \
  --name shell-town \
  --restart unless-stopped \
  -p 3000:3000 \
  -v $(pwd)/data:/app/data \
  -v $(pwd)/pets:/app/web/dist/pets \
  -e ADMIN_USERNAME=admin \
  -e ADMIN_PASSWORD=你的强密码 \
  -e JWT_SECRET=你的随机密钥 \
  shell-town:latest
```

> 宠物素材目录 `./pets` 无需手动准备：镜像内置出厂素材，容器启动时会自动把缺失的文件补进挂载目录
> （只补缺失，不覆盖你改过的图）。想换图/加图，往宿主机 `./pets/<物种key>/` 放文件即可，刷新页面生效。

### 方式三：本地开发

```bash
# 安装依赖
npm install

# 同时启动前后端（开发模式）
npm run dev
# 前端: http://localhost:5173
# 后端: http://localhost:3000
```

## 首次登录

系统首次启动时会自动创建管理员账号：

| 项目 | 默认值 |
|---|---|
| 用户名 | `admin` |
| 密码 | `admin123` |

> ⚠️ **请登录后立即修改密码**（家长端 → 设置）。
> 默认密码是公开的，不改会有安全风险。

登录后：
1. 在 **家长端** 添加孩子账号，设置孩子的 **PIN 码**
2. 在 **积分** 里检查/调整默认的加分、扣分项目
3. 在 **商店** 里添加可兑换的商品（想让孩子养宠物就上架几个 **宠物道具**，效果填在 `pet_effect` 里）
4. 在 **任务** 里发布任务
5. 孩子即可用自己的账号 + PIN 登录：**主页**看积分 → **宠物**页领养一只 → 做任务赚积分 → 买道具喂养进化
6. （可选）在 **宠物** 页改物种中文名、调成长阈值、换立绘

## 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | `3000` | 服务监听端口 |
| `DATA_DIR` | `/app/data` | 数据目录（SQLite 数据库存放位置） |
| `ADMIN_USERNAME` | `admin` | 首次初始化时创建的管理员用户名 |
| `ADMIN_PASSWORD` | `admin123` | 首次初始化时创建的管理员密码 |
| `JWT_SECRET` | `please-change-this-secret` | 登录令牌签名密钥，**务必修改** |

> ℹ️ `ADMIN_USERNAME` / `ADMIN_PASSWORD` **仅在数据库为空（首次启动）时生效**。
> 如果数据库中已存在家长账号，这两个变量不会覆盖已有账号。

### 修改配置

推荐用 `.env` 文件（`docker-compose.yml` 同目录）：

```dotenv
ADMIN_USERNAME=admin
ADMIN_PASSWORD=改成你的强密码
JWT_SECRET=改成一串随机字符串
```

然后重新执行 `docker compose up -d`。

## 数据存储与备份

数据分两部分：**结构化数据**（账号、积分、任务、宠物经验/状态、物种名与阈值）在 SQLite 里，
**宠物立绘素材**在 `pets/` 图片目录里。

```
data/
├── shell-town.db         # 主数据库（含 pet_species 物种表、pets 养成数据）
├── shell-town.db-wal     # 预写日志
└── shell-town.db-shm     # 共享内存

pets/                     # 宠物素材（Docker 下为宿主机 ./pets）
├── _egg.webp
└── <物种key>/1~4.webp
```

**备份**：直接复制 `data/` 和 `pets/` 两个目录即可（建议连同 `-wal`、`-shm` 一起复制）。

**恢复**：把备份的目录放回原位，重启容器。

> ⚠️ 不要单独删除 `data/` 目录，否则所有账号、积分记录和宠物养成进度都会丢失。
> 只删 `pets/` 里的图不会丢数据，但宠物会回退成 emoji 兜底图标（重新启动容器可自动补回出厂素材）。

> 📌 从旧版本（piggy-bank / money-jar）升级：`data/` 与 `pets/` 目录可原样复用，
> 数据库文件会在首次启动时自动改名为 `shell-town.db`，数据无损。

## 常见问题

### 1. 构建失败，提示找不到文件

确认在**包含 `docker-compose.yml` 的目录**下执行命令，且该目录下有 `Dockerfile`、`server/`、`web/`。

### 2. 端口被占用

修改 `docker-compose.yml`：

```yaml
ports:
  - "3100:3000"      # 把左边的 3000 改成其它端口
```

保存后执行 `docker compose up -d --build`，再访问新端口。

### 3. 构建时网络超时（国内环境）

`Dockerfile` 已内置国内镜像源配置（`registry.npmmirror.com`），正常情况下无需处理。
若仍失败，通常是网络波动，重新执行一次构建即可。

### 4. 忘记密码

删除 `data/shell-town.db` 会重置所有数据（**慎用**）。
`ADMIN_USERNAME` / `ADMIN_PASSWORD` 环境变量只在数据库为空时生效。

### 5. 能在外网访问吗？

默认只监听局域网。若要外网访问，建议使用 **内网穿透** 或 **反向代理 + HTTPS**，
**不要**直接把 3000 端口暴露到公网。

### 6. 想换宠物形象 / 加一只新宠物

- 换图：把图放到宿主机 `./pets/<物种key>/`（阶段 1~4 命名为 `1.webp`~`4.webp`），刷新页面生效
- 加新宠物：家长端 **宠物** 页 → 新建物种（填名字和目录 key）→ 上传图片，全程无需改代码或重建镜像
- 图没更新：多为浏览器缓存，Ctrl+F5 强刷即可
- 家长端改完，孩子端要重启容器才看到吗？**不用**。改动会实时广播给在线端，
  孩子端会自动刷新物种列表和立绘；即使没连上 WS，重进宠物页/重开选择弹窗也会拉取最新数据

### 7. 宠物图片全变成 emoji 了

说明宠物素材目录是空的（或挂载目录被清空）。重启容器会自动补齐出厂素材：
`docker compose restart`。若仍不行，检查 `./pets` 目录权限，以及容器日志中是否有挂载相关报错。

> 若只有**个别**新物种显示 emoji，通常是该物种一张图都还没传 —— 去家长端 **宠物** 页给它传图即可。
> 只传了部分阶段也没关系：缺的那几级会自动借用该物种已有的图顶上（先近后远），
> 不会变成 emoji；想把每级都做成不同形态，把缺的阶段补齐即可。

3. 孩子的 PIN 码不要设置得过于简单
4. 定期备份 `data/` 目录
5. 不要将服务直接暴露到公网
